🚀 SQL + Power BI End-to-End Project: Pizza Sales Analysis Dashboard 



I recently completed a full SQL + Power BI project where I built a complete Pizza Sales Analytics system from scratch — starting from database creation to interactive visualizations.



🧩 🔹 Phase 1: SQL Database Creation & Querying

I began by designing and creating a relational database using SQL Server.



 Key steps included:



Creating tables for Orders, Order Details, Pizzas, Categories, Sizes

Applying data cleaning, fixing missing & incorrect entries



Writing SQL queries for:



->Total revenue

->Monthly and daily sales trends

->Best/worst-selling pizzas

->Category-wise and size-wise performance

->Aggregations like SUM(), COUNT(), AVG()

->Joins between multiple tables

->CTE-based transformations

This ensured that the dataset was accurate, structured, and ready for analysis.



📊 🔹 Phase 2: Interactive Power BI Dashboard



After preparing the data through SQL, I imported it into Power BI and created a fully interactive dashboard with slicers, page navigation, and custom visuals.
